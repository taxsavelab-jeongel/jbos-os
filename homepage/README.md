# 정엘가업승계연구소 홈페이지

가업승계·중소기업 M&A 전문 세무법인 홈페이지를 벤치마킹해, **정엘가업승계연구소 브랜드 아이덴티티**로
새로 설계한 정적 웹사이트입니다. 의존성 없는 HTML/CSS/JS 3파일 구성이며 그대로 업로드하면 동작합니다.

```
homepage/
├── index.html              # 전체 페이지
└── assets/
    ├── styles.css          # 브랜드 디자인 시스템
    ├── calculators.js      # 진단 도구 계산 엔진 (세법 로직)
    ├── site.js             # 내비게이션 · 계산기 UI · 폼
    └── mark.svg            # 파비콘 / 심볼
```

## 전문 진단 도구 7종

계산기 명칭은 “○○ 계산기” 대신 **전문성과 직관성을 함께 갖춘 명칭**으로 교체했습니다.

| # | 명칭 | 하는 일 | 근거 법령 |
|---|---|---|---|
| 1 | **승계세액 비교 시뮬레이터** | 가업승계 증여특례 vs 일반 증여세율 세액 비교 | 조특법 §30의6, 상증법 §26 |
| 2 | **상속세 부담 진단기** | 일괄·배우자·금융재산·가업상속공제 반영 납부세액 | 상증법 §18의2·19·21·22 |
| 3 | **기업가치 평가 시뮬레이터** | 비상장주식 1주당 평가액 및 보유지분 가치 | 상증법 §63, 시행령 §54 |

| 6 | **이익잉여금 인출전략 비교기** | 급여·배당·퇴직금 3경로 실수령 비교 | 소득세법 §55·129, 법인세법 §55 |
| 7 | **사전증여 분산 설계기** | 10년 합산 주기를 활용한 분산 증여 효과 | 상증법 §53·57 |

### 계산 엔진 설계 원칙

- 세율표는 `calculators.js` 상단 `TABLE`에 **누진공제 방식**으로 분리해 두었습니다.
  세법이 개정되면 이 표만 수정하면 전 계산기에 반영됩니다.
- 지방소득세 10%는 `LOCAL` 계수, 신고세액공제 3%는 `FILING_CREDIT`,
  당좌대출이자율 4.6%는 `LOAN_RATE`, 순손익가치 환원율 10%는 `EARN_RATE` 상수로 관리합니다.
- 퇴직소득세는 근속연수공제 → 환산급여 → 환산급여공제 → 12분의 1 방식까지 실제 산식을 구현했습니다.
- 6번 비교기는 **회사가 부담하는 세전 재원을 세 경로 모두 동일하게 맞춰** 비교합니다.
  (배당은 손금이 아니므로 법인세를 먼저 차감한 금액만 지급 가능하도록 처리)
- 모든 계산기는 입력 누락·0·음수에 대한 가드를 두어 `NaN`이 화면에 노출되지 않습니다.

### 검증

`node` 환경에서 세율표 검산 및 7개 계산기 전수 엣지케이스 테스트를 통과했습니다.
(증여 과표 10억 → 2.4억, 30억 → 10.4억, 50억 → 20.4억 등 법정 세액과 일치)

## 배포

정적 파일이므로 `homepage/` 폴더 내용을 그대로 올리면 됩니다.
회사 표준 배포 경로(Cloudflare Workers, `jeongellab.com` 서브도메인)를 쓰는 경우
`jeongel-web-deploy` 스킬의 절차를 따르십시오. **「배포」 버튼까지 눌러야 반영됩니다.**

로컬 확인:

```bash
python3 -m http.server 8899 --directory homepage
# http://127.0.0.1:8899
```
